# VoxFlow-Assistant

Context-Aware Voice AI & Interview Assistant

## Overview

VoxFlow-Assistant is a full-stack voice AI application built with
React and Java Spring Boot.

The application allows users to communicate with an AI assistant
through voice, maintain conversation context, execute application
commands, and practice technical interviews through a voice-based
interview mode.

## Core Architecture

React Frontend
        ↓
Spring Boot Backend
        ↓
Speech-to-Text
        ↓
Intent / Assistant Engine
        ↓
Text-to-Speech
        ↓
React Frontend
